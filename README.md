# OpenClaw Skills Branch

Ветка **skills** содержит коллекцию готовых к использованию навыков (skills) и плагинов для фреймворка OpenClaw.

## Структура

- **icalendar-sync/** - Навык для синхронизации календарей в формате iCalendar
  - Поддерживает интеграцию с различными календарными сервисами
  - Многоязычная поддержка
  - Полная документация и примеры использования

## Использование

Каждый навык в этой ветке может быть независимо интегрирован в ваш проект OpenClaw.

Подробную информацию о каждом навыке можно найти в его директории.

## Версия

Эта ветка поддерживает OpenClaw версии 2.0 и выше.
